AUTONOMOUS DRONE SCANNER AI
-----------------------------------------
Mode 1: Lost Object Identification
-Identifies  objects like (wallets,keys,purses and phones) by scanning a user defined region within a city.
- Utilizes a Sonar System(which utilizes sound waves in order to avoid hitting obstacles) In order to avoid buildings and other objects.
- The model we trained to identify lost objects was a YOLOv11n(n stands for nano).
- We trained the model on images of wallets,keys,purses and phones from our unity environment.




MODE 2: Identifying People Trapped in Burning Buildings
-Helps Identify people who are trapped in burning buildings which could save their lives.
-Also utilizes a Sonar System(which utilizes sound waves in order to avoid hitting obstacles)
-It utilizes the YOLOv11n model to identify people
